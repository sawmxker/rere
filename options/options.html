Addons

Manage per-site style and script overrides. Each addon is a folder bound to a site (for example myanimelist.net). Inside a folder you can create files — a page style (CSS) or a script (JS). CSS rules get !important automatically, so your changes override the site's own styles. This lets advanced users add a dark theme to any site, integrate a third-party player, and more.

Help

Quick reference for using reré: Quick ReSearching.

How to use

On IMDb, MyAnimeList, or Goodreads pages:

  • Click the reré:Search button on the page to search using your default engine.
  • Click the dropdown arrow next to the button to pick from your Quick Search Menu.

Context menu search (any page):

  • Select any text, right-click, and choose "reré:Search" → pick a profile → pick a search engine.

Profiles:

  • Each profile stores its own search engines, menu items, query template, and suffix.
  • Assign a profile to a site (IMDb, MAL Anime, MAL Manga, Goodreads) so it activates automatically on that site.
  • Create separate profiles for different search needs.

Default Search Engine — opens when you click the main button on a page.

Quick Search Menu Items — appear in the dropdown for quick access to multiple resources.

Tips

  • Use {query} in your search URLs to control where the title is placed. If omitted, it is appended at the end.
  • The Query Template setting controls whether the year is included: title or title+year.
  • Add a Search Suffix like watch or stream to refine results.
  • Use the MAL Quick Link (Additional Settings → MyAnimeList) to get direct MAL page links via the Jikan API when searching from other sites.
  • Drag the ⋮⋮ handle to reorder engines and menu items.
  • Export/import your settings via the ⋮ button next to Save.
  • Enable Firefox Sync to share settings across devices.

Supported sites

  • IMDb — movies, TV shows, games, and more
  • MyAnimeList — anime (/anime/) and manga (/manga/) pages
  • Goodreads — book pages
